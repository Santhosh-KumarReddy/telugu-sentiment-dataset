# telugu-sentiment-dataset
A manually annotated dataset of 1,287 Telugu YouTube comments labeled for sentiment analysis (Positive, Negative, Neutral).


## 📊 About the Dataset

This dataset was created as part of a study addressing sentiment classification in Telugu, a morphologically rich and under-resourced language. Due to the absence of existing public sentiment-labeled data in Telugu, we developed this custom dataset.

- **Source:** YouTube comments from videos across 4 categories:
  - Movie Reviews
  - Product Reviews
  - Sporting Events
  - Social Moments
- **Language:** Telugu (script), optionally with English translations
- **Annotations:** Manually labeled with one of 3 sentiment classes
- **Total Comments:** 1,287
- **Vocabulary Size:** 7,179 unique words
- **Average Comment Length:** ~12.34 words


## 🔍 Usage

This dataset can be used for:
- Sentiment classification experiments
- Cross-lingual or multilingual NLP studies
- Benchmarking low-resource language models

The comments used in this dataset were obtained via the YouTube Data API. The authors thank annotators for their contribution to data labeling.
